# Activity OS 管理后台原型

基于 Vue 3、TypeScript、Vite 和 Element Plus 的活动配置后台第一版。

## 已实现页面

- 工作台：活动指标、近期活动、发布风险。
- 活动管理：关键词、状态、模板筛选，活动复制与配置入口。
- 页面编排：模板选择、模块库、模块排序、启停、终端范围、背景素材上传和图片预览。
- 任务中心：执行器、任务周期、目标、前置条件与奖励配置视图。
- 奖品与奖池：奖品类型、中奖概率、库存、用户限中与概率检查。
- 发布审核：配置健康分、自动校验和审核流程。

当前使用本地 mock 数据，尚未接入活动中心、商品中心、抽奖和奖励履约接口。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
